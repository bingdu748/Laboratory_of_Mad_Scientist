# Code Wiki · 项目总览与整体架构

> 本文档系本地生成的 **Code Wiki**，用于帮助开发者快速理解、维护和扩展本项目。文档全部为静态 Markdown，仅存于本地，不参与仓库自动生成流程。

***

## 1. 项目是什么

这是一个 **基于 GitHub Issues 的静态博客系统（GitBlog）**。

* 仓库地址：<https://github.com/volatile-Quartz/Dr_Wunderkammer>

* 用途：把个人日记/思考以 **GitHub Issue** 的形式存放，用 Python 脚本拉取并生成 `README.md`、RSS `feed.xml`、`posts/**` 系列 Markdown 文章，最终由 GitHub Pages / Actions 自动渲染成静态站点。

* 定位：内容即数据、脚本即建站工具、CI 即发布流水线。所有"文章"、标签、评论都来自 GitHub 本仓库本身。

**核心理念**：作者在 README 中写道 *"记录自我，留存活过的痕迹"*——用 GitHub 账号自有的 Issue 作为内容载体，通过自动化脚本与 CI 同步到仓库内，避免额外依赖第三方数据库。

***

## 2. 整体架构

整个系统由四层构成：

```
┌────────────────────────────────────────────────────────────────────┐
│ ① 数据源层（GitHub）                                                │
│   - Issues（一篇文章 = 一个 Issue）                                  │
│   - Labels（标签 = 文章分类）                                        │
│   - Comments（评论 = 正文分段，作者本人评论才会被收录）               │
│   - Pull Requests（第三方 PR，用于 CHANGELOG）                       │
└────────────────────────────────────────────────────────────────────┘
                 │  PyGithub（GitHub REST API 客户端）
                 ▼
┌────────────────────────────────────────────────────────────────────┐
│ ② 处理层（Python 脚本，见 scripts/）                                │
│   scripts/utils.py           公共工具：认证/时间/统计/元数据          │
│   scripts/generate_posts.py  把 Issue 渲染成 posts/**/*.md           │
│   scripts/update_readme.py   生成 README.md / feed.xml / CHANGELOG   │
└────────────────────────────────────────────────────────────────────┘
                 │  落盘
                 ▼
┌────────────────────────────────────────────────────────────────────┐
│ ③ 产物层（仓库根目录）                                              │
│   posts/**/*.md          文章（按标签分目录）                        │
│   posts/index.json       文章目录索引                                │
│   posts_export.json      JSON 结构化全量导出                          │
│   .temp_metadata.json    字数/图片统计元数据缓存                     │
│   README.md              门户首页                                    │
│   feed.xml               RSS 订阅                                    │
│   CHANGELOG.md           第三方 PR 记录                              │
└────────────────────────────────────────────────────────────────────┘
                 │  git commit / push
                 ▼
┌────────────────────────────────────────────────────────────────────┐
│ ④ 自动化层（GitHub Actions，见 .github/workflows/）                 │
│   generate_readme.yml  拉取 Issue→生成产物→提交推送（事件+定时）      │
│   daily-squash.yml     每天把当天提交压缩为一条汇总                   │
│   generate_site.yml    用 isite+zola 构建 Pages 静态站点              │
└────────────────────────────────────────────────────────────────────┘
```

## 3. 核心设计决策

| 决策                   | 说明                                           |
| -------------------- | -------------------------------------------- |
| GitHub Issue 作为"数据库" | 文章、标签、评论、PR 全部来自仓库自身，无外部存储                   |
| `master` 为唯一内容分支     | 依赖 `master-branch-write` 互斥锁防止多工作流并发写冲突      |
| 评论作为正文分段             | Issue 正文当"文档说明"，作者本人评论按时间顺序追加为 `##` 分段       |
| 标签目录分类               | 文章按标签落到 `posts/<label>/`，无标签落到 `no-label/`   |
| 统计三层回退               | 字数/图片优先读 `.md` 文件 → 元数据缓存 → 回退到 `issue.body` |
| 合并冲突策略               | 生成类产物走 `merge=ours`，rebase 冲突时保留本地生成版本       |
| 时间戳防抖                | README 等仅时间戳变化时不提交，避免无意义 commit 噪音           |

## 4. 目录总览

```
.
├── .github/
│   ├── workflows/
│   │   ├── generate_readme.yml    # 主流水线：拉取+生成+推送
│   │   ├── daily-squash.yml       # 每日提交压缩
│   │   └── generate_site.yml      # GitHub Pages 站点部署
│   └── dependabot.yml             # 依赖自动升级（GitHub Actions group）
├── scripts/
│   ├── utils.py                   # 公共工具模块
│   ├── generate_posts.py          # 文章生成模块
│   ├── update_readme.py           # README/RSS 更新模块
│   ├── test_utils.py              # 单元测试
│   ├── run_local.sh               # 本地运行脚本（Linux/macOS）
│   └── run_local.bat              # 本地运行脚本（Windows）
├── posts/                         # 生成的文章（按标签分目录）
│   ├── index.json                 # 目录索引
│   ├── my-diary/                  # 标签 my-diary
│   ├── no-label/                  # 无标签
│   └── the-lore/                  # 标签 the-lore
├── README.md                      # 生成的门户首页
├── CHANGELOG.md                   # 生成的第三方 PR 记录
├── feed.xml                       # 生成的 RSS
├── posts_export.json              # 生成的 JSON 全量导出
├── .temp_metadata.json            # 统计元数据缓存
├── requirements.txt               # 依赖（仅 PyGithub）
├── .gitattributes                 # merge=ours 冲突策略
└── LICENSE                        # 许可证
```
