# 01 · 模块职责

> 说明本项目各目录、脚本、工作流的职责边界。所有路径均相对仓库根目录。

---

## 1. `scripts/` — Python 处理层

统一约定：所有脚本开头都执行 `sys.path.insert(0, <项目根>)`，使脚本既能以 `python scripts/xx.py` 直接运行，也能互相 `from scripts.xxx import ...`。

### 1.1 `scripts/utils.py` — 公共工具模块

**职责**：被 `generate_posts.py` 与 `update_readme.py` 共同依赖的"地基"。

- 全局日志与常量（标签、路径、时区）
- GitHub 认证与身份判定
- 时间格式化（统一转北京时间 UTC+8）
- Markdown 纯文本化、字数统计、图片统计
- 元数据（`.temp_metadata.json`）读写
- 环境信息打印（跨环境调试）

**为什么单独成模块**：字数/图片统计与身份/时间逻辑在多处复用，抽成公共层避免重复实现，保证统计口径一致。

### 1.2 `scripts/generate_posts.py` — 文章生成模块

**职责**：把 GitHub Issues 渲染成 `posts/**/*.md` 文件。

- 按标签把文章归入不同子目录
- 生成机器可读的头部注释块（issue 元数据）
- 拼接 Issue 正文 + 作者本人评论分为多个 `##` 分段
- 关闭的 Issue 触发文件删除
- 生成 `posts_export.json`（全量导出）和 `posts/index.json`（目录索引）

### 1.3 `scripts/update_readme.py` — README / RSS 更新模块

**职责**：读取仓库全部 Issue/标签，在内存中拼装并生成 `README.md`、`feed.xml`、`CHANGELOG.md`。

- 文章列表 / 置顶 / 待办 / 标签分类区块
- 博客统计（总字数、总插图、24h 新增/更新）
- RSS 2.0 feed
- 第三方 PR 记录到 CHANGELOG
- 内容无变化时跳过落盘（防抖）

### 1.4 `scripts/test_utils.py` — 单元测试

**职责**：用 `unittest` 验证过滤逻辑与跨平台统计一致性。

- 用 `MagicMock` 伪造 Issue 对象测试 `is_pull_request` / `should_include_issue`
- `_clean_markdown` / `_count_words` / 图片计数 / 换行符归一化
- 跨平台一致性（Unix `\n` 与 Windows `\r\n` 结果一致）

### 1.5 `scripts/run_local.sh` / `scripts/run_local.bat`

**职责**：本地一键运行指南脚本。检查 Python/pip → 安装依赖 → 交互式输入 Token 与仓库名 → 调用脚本。指向的是 `main.py`（历史遗留入口，仓库中当前实际入口为 `generate_posts.py` / `update_readme.py`）。

## 2. `.github/workflows/` — CI/CD 自动化层

| 工作流 | 触发方式 | 职责 |
|--------|----------|------|
| `generate_readme.yml` | push / issue 事件 / `issue_comment` / 定时(22:15 北京) / 手动 | 拉取 Issue→生成 posts/README/feed→提交推送 |
| `daily-squash.yml` | 定时(23:30 北京) / 手动 | 把当天提交 `git reset --soft` 后压缩为一条"每日提交汇总" |
| `generate_site.yml` | push / 定时(23:40 北京) / 手动 | 用 isite 生成文章并交给 zola 构建，部署到 GitHub Pages |

三者通过 `master-branch-write` 这个 `concurrency` 组互斥，防止并发写 master。

---

## 3. `.github/dependabot.yml`

**职责**：自动扫描 GitHub Actions 依赖升级（按 `github-actions` 分组）。升级提交会以"非本人 PR"形式出现，被 `update_readme.py` 识别并写入 `CHANGELOG.md`。

---

## 4. 产物/数据文件（由脚本生成）

| 文件 | 生成者 | 职责 |
|------|--------|------|
| `posts/**/*.md` | generate_posts | 每篇 Issue 渲染成的 Markdown 文章 |
| `posts/index.json` | generate_posts | 全部文章路径/字数/图片/SHA256 索引 |
| `posts_export.json` | generate_posts | 全量元数据+正文的结构化 JSON |
| `.temp_metadata.json` | generate_posts | issue→字/图统计缓存，供 README 复用 |
| `README.md` | update_readme | 博客门户首页 |
| `feed.xml` | update_readme | RSS 订阅 |
| `CHANGELOG.md` | update_readme | 第三方 PR 记录 |
