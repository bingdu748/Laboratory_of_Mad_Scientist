# 03 · 依赖关系

> 梳理项目各层的依赖关系，包括 Python 包依赖、GitHub 服务依赖、外部工具依赖。

---

## 1. Python 依赖

唯一的外部依赖：`PyGithub`，见 `requirements.txt`：

```
PyGithub==1.59.1
```

### 作用

PyGithub 是 GitHub REST API v3 的 Python 客户端，负责：

1. 认证登录（Token 鉴权）
2. 获取 Issues 列表、单个 Issue
3. 获取 issue comments
4. 获取仓库标签
5. 获取 issue 元数据（创建/更新时间、state、labels、html_url）

### 兼容处理

代码同时兼容新旧认证方式：

```python
try:
    import github.Auth
    auth = github.Auth.Token(token)
    return github.Github(auth=auth)      # 新版
except ImportError:
    return github.Github(token)          # 旧版回退
```

## 3. GitHub 服务依赖

本项目核心数据存储就是 GitHub 本身，所以强依赖以下 GitHub 服务：

| 服务 | 用途 |
|------|------|
| GitHub Issues | 文章存储（一个 Issue = 一篇文章）+ 标签分类 + 评论分段 |
| GitHub Labels | 文章分类 |
| GitHub Pull Requests | 第三方依赖升级（Dependabot）→ CHANGELOG |
| GitHub Actions | CI 自动化流水线（生成 → 压缩 → 部署）|
| GitHub Pages | 静态站点部署 |
| GitHub REST API | PyGithub 客户端访问数据 |
| GitHub Token 环境变量 | `secrets.GITHUB_TOKEN`，Actions 自动注入 |

## 4. CI 阶段外部工具依赖（generate_site.yml）

在部署 GitHub Pages 阶段，会下载使用两个预编译二进制：

| 工具 | 版本 | 来源 | 用途 |
|------|------|------|------|
| `isite` | `v0.2.2` | [kemingy/isite](https://github.com/kemingy/isite) | 从 Issues 生成静态 Markdown 目录结构 |
| `zola` | `v0.20.0` | [getzola/zola](https://github.com/getzola/zola) | 把 Markdown 编译为静态 HTML 站点 |

- **获取方式**：通过 GitHub CLI `gh release download` 直接从发布页下载
- **运行位置**：GitHub Actions Runner（临时），不存到仓库
- **产物位置**：`output/public/` → 由 `actions/upload-pages-artifact` 上传部署

### URL 计算

```python
REPO=$(echo "${{ github.repository }}" | cut -d '/' -f 2)
BASE_URL="https://${{ github.repository_owner }}.github.io/$REPO"
```

## 8. 依赖版本锁定策略

| 依赖 | 版本控制方式 |
|------|--------------|
| PyGithub | `requirements.txt` 锁定 `==1.59.1` |
| Actions 复用 | 每个 action 用 `@v6`（如 `actions/checkout@v6`），由 Dependabot 自动升级 |
| isite | `ISITE_VERSION: v0.2.2` 硬编码在 workflow |
| zola | `ZOLA_VERSION: v0.20.0` 硬编码在 workflow |
| Python | `generate_readme.yml` 指定 `python-version: "3.8"` |

Dependabot 在 `.github/dependabot.yml` 中只监控 `github-actions` 分组，每周检查一次。

## 9. 权限依赖

| 场景 | 需要的权限 |
|------|-----------|
| GitHub Actions CI | `secrets.GITHUB_TOKEN`（自动注入）需要 `contents: write` |
| GitHub Pages 部署 | `pages: write`, `id-token: write` |
| 本地运行 | Personal Access Token 需要 `repo` scope（读写仓库）|
